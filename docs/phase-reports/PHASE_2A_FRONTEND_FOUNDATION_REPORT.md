## 7. Application architecture

- **Framework:** Next.js 16 App Router
- **Structure:** `src/` directory with `@/*` import alias
- **Rendering:** Server components by default; client components for theme and Three.js only
- **Routes:** `/` (foundation preview only)
- **Scope:** Foundation shell — not the completed Stitch homepage

Confirmed exclusions: no customer portal, login, payments, tracking, database, quote backend or Spline implementation.

## 8. Theme architecture

- **Provider:** `next-themes` with `attribute="class"`
- **Default:** System
- **Modes:** System, Light, Dark
- **Persistence:** Handled by next-themes (localStorage)
- **Implementation:** CSS variables in `globals.css` with `.light` and `.dark` class overrides
- **Control:** `ThemeMenu` in site header

## 9. Typography configuration
