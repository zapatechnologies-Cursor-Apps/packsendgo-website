# PackSendGo Website

Premium public marketing and lead-generation website for PackSendGo.

## Current phase

Phase 0 — Project foundation and design authority.

## Approved V1 direction

- Next.js
- React
- TypeScript
- Tailwind CSS
- Node.js
- Prisma
- MySQL
- Hostinger Cloud Startup
- GitHub
- Google Stitch
- Stitch MCP
- Cursor
- Spline warehouse experience
- Real warehouse video or Matterport tour
- Structured quotation form
- External transactional email provider
- Cloudflare Turnstile or equivalent spam protection

## Primary conversion objective

Generate qualified quotation enquiries for ecommerce fulfilment, warehousing, pick-and-pack and dispatch services.

## Current restrictions

PackSendGo V1 does not include:

- Customer accounts
- Customer dashboard
- Live inventory
- Shipment tracking
- Carrier API integrations
- Ecommerce platform API integrations
- Online payments
- Automatic quotations
- AI pricing
- AI chatbot
- Customer file uploads
- Live WebSocket features
- Redis
- Background workers
- Large content-management system
- Mobile applications

## Development workflow

- ChatGPT is the programme architect.
- Cursor is the implementation agent.
- Google Stitch is the design source.
- GitHub is the source-control authority.
- Hostinger Cloud Startup is the approved production host.
- Cursor must operate in API Saving Mode.
- Cursor must not run Git commands.
- The Product Owner performs all Git operations.
